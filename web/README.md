# Frontend Website Pengajuan Finance

Frontend Next.js untuk aplikasi Finance SL Indonesia. Petunjuk konfigurasi database, migrasi, API, dan cara menjalankan ada di [README utama](../README.md).

Jalankan dari direktori proyek utama dengan `npm run dev:web`, atau dari folder ini dengan `npm run dev`. API Express harus berjalan di port 3100 kecuali `API_URL` diatur ke alamat lain.
